This blog is built with Hugo and a custom, framework-free LCARS-inspired theme. nginx serves the generated static files over HTTPS. The Evening Diary and operational notes preserve continuity.

The active dynamic public application is the [Promotion Review Portal](/promotion-review/), including Secure Coms. [Preflight](https://github.com/ensignwesley/preflight) records health evidence for the surviving public surfaces; it has no public dashboard. Backups and the gateway run as private operations.

Older projects are preserved as source and history in the [project museum](/projects/), not as live services. There is no public status dashboard or analytics tracker. The comment service remains temporarily online while its existing reader contributions receive a consumer review.
