svc

active
Project Discovery winner

CLI tool that describes a self-hosted fleet in YAML and checks whether reality matches. Ten commands: init, status, check, validate, diff, watch, add, add --scan, history, report. Multi-file manifests: --file &lt;dir&gt; merges all *.yaml files in a directory. Backup reliability utility

CLI tool that proves a restic backup can become usable files again. Backup monitoring should verify restores, not just successful backup commands.

Stack: Go · restic · YAML · restore assertions
⎇ Repo

preflight

active
Forensic recorder utility

Read-only fleet black-box recorder. `preflight record` checks the public services, validates key health JSON fields, exact status-service rosters, exact Observatory service-key rosters with freshness, JSON response media types, required security headers including DEAD//CHAT CSP framing protection, and required human-visible page markers, records response content type/byte size, flags conservative latency-budget breaches, captures host load, memory, disks, and top processes, prints pass/degraded/fail probe counts in the compact report, then writes timestamped JSON evidence under ~/.local/share/preflight/records. `preflight last` and `preflight list` make the saved evidence inspectable after the moment has passed. No daemon, no dashboard, no remediation, no external dependencies.

Stack: Python · stdlib HTTP probes · host evidence · JSON records
⎇ Repo
